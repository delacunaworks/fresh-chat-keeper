## 詳細説明文

### Fresh Chat Keeper — ゲーム配信チャットのネタバレフィルター

ゲームのライブ配信やアーカイブを観ているとき、チャット欄に流れるネタバレや匂わせ、指示コメントに嫌な思いをしたことはないでしょうか。

**Fresh Chat Keeper** は、YouTubeのゲーム配信チャットをリアルタイムで監視し、ネタバレをはじめとしたこれらのコメントを自動的に非表示にするChrome拡張機能です。


### 主な機能

**2段階AIフィルタリング**
- Stage 1（瞬時）: キーワードマッチによる高速フィルタ
- Stage 2（AI判定）: Claude AIが文脈を理解してネタバレかどうかを精密に判定
- 誤検出を最小限に抑えつつ、見逃しを防ぐ2重チェック構造

**アーカイブ・ライブ両対応**
- アーカイブ（録画配信）のチャットリプレイをフィルタ
- ライブ配信中のリアルタイムフィルタリングにも対応

**ジャンル別テンプレート**
- RPG、推理・ミステリー、アクション・ホラーなどジャンルを選ぶだけで精度が向上
- 攻略ヒント・指示系コメント（「まだいってないところあるよ」「これ負けイベだよ」等）も検出

**ゲーム進行状況に連動**
- ゲームの進行状況（どこまでクリアしたか）を登録すると、すでに通過した部分への言及は非表示にしない
- まだ到達していない部分のネタバレと、すでに通過済みの内容を自動的に区別

**動画タイトルからゲームを自動推測**
- 動画タイトルからプレイ中のゲームを自動的に推測し、より精度の高い判定を実現

**マルチカテゴリフィルタ（v0.4.0 新機能）**
- ネタバレに加え、暴言・誹謗中傷 / スパム・連投 / 無関係な話題・他配信者言及 / 指示厨・攻略押し付け を AI が判定
- カテゴリごとに ON/OFF・強度を設定可能（新カテゴリは初期 OFF。必要なものだけ有効化）

**ユーザーブロック（v0.4.0 新機能）**
- 気になる投稿者をワンクリックでブロックし、過去コメントも含めて非表示
- 取り消し（Undo）・ブロックリスト管理に対応。ブロック情報は端末内のみに保存

**スパム自動検出（v0.4.0 新機能）**
- 同一コメントの連投・URL 羅列・絵文字連打などをAI判定前に高速検出

**視聴者フラグ機能（v0.5.0 新機能・オプトイン）**
- フィルタに繰り返し引っかかる視聴者を 4 段階（問題なし / 軽微 / 注意 / 要注意）で可視化し、ブロック判断を支援
- 表示スタイル（アイコン / 色 / ホバー時のみ / レッドのみ）・追跡期間（セッション / 7日 / 30日）・感度を選択可能
- コメント横の「📊 統計を見る」で視聴者ごとの内訳・日別推移を確認。ポップアップの「フラグ視聴者」タブで一括ブロックも可能
- 初期状態は OFF。統計はすべて端末内に保存され、外部送信は一切ありません（v0.3.5 の opt-in データ収集とは別物）

**字幕連動（v0.6.0 新機能・実験的・オプトイン）**
- YouTube の字幕（CC）が表示されている配信で、配信者の直近の発言を AI 判定の文脈に加え、ネタバレ等の判定を補助
- 字幕はブラウザ内で取得し、判定リクエストに含めて送信するのは ON のときのみ（音声の録音はしません）
- ゲーム実況など自動字幕が少ない配信では効果は限定的で、その場合は何もせず通常どおり動作します
- 初期状態は OFF（オプトイン）。OFF のときは v0.5.0 と完全に同一の挙動です

**カスタムNGワード**
- 自分だけのNGワードリストを作成し、任意のコメントを即時フィルタ

**3段階のフィルター強度**
- 厳格: 明確なネタバレ、匂わせ、攻略ヒントをすべてブロック
- 標準: 明確なネタバレと匂わせのみブロック（デフォルト）
- 緩め: 明確なネタバレのみをブロック


### 使い方

1. Chrome Web Storeからインストール（アカウント登録・ログイン不要）
2. YouTubeでゲーム配信のページを開く
3. 右上のFresh Chat Keeperアイコンをクリックしてポップアップを開く
4. ゲームタイトルまたはジャンルを選択して完了

設定はすぐに反映され、以降は自動でフィルタリングが動作します。


### プライバシーへの配慮

- **データはローカル保存**: 設定・判定結果はすべてお使いのブラウザ内にのみ保存
- **チャット内容はサーバーに保存しない**: AI判定のためにコメントテキストを送信しますが、ログとして保存・記録することは一切ありません
- **APIキー不要**: Anthropic APIキーをユーザーが用意する必要はありません。Fresh Chat Keeperが安全なプロキシ経由で管理しています
- **アカウント登録不要**: インストールするだけで即使用可能

#### データ収集機能（任意・opt-in、v0.3.5 から）

ネタバレ判定の改善にご協力いただける方向けに、判定ログを当社サーバーに蓄積する機能を追加しました。

- **デフォルトはオフ**。ポップアップで明示的にトグルをオンにし、同意モーダルで承諾した場合のみ有効化されます
- 投稿者識別子はサーバー側で SHA-1 ハッシュ化され、平文では保存されません
- いつでもポップアップから取り消せます。取り消し時は過去のサーバー側ログ（90 日以内）も削除されます
- 詳細はプライバシーポリシーの「opt-in 同意に基づくデータ収集」セクションを参照してください

詳しいプライバシーポリシー: https://github.com/delacunaworks/fresh-chat-keeper/blob/main/docs/privacy-policy.md


### ご利用にあたって

AIが文脈を読んでネタバレ等を判定しますが、すべてのケースで完全にブロックすることは保証できません。対応タイトルとして登録されているゲームではより精度の高い判定が可能です。対応タイトル外のゲームでも、ジャンル別テンプレートやカスタムNGワードを組み合わせることで精度を高めることができます。誤った判定（誤フィルタ・見逃しの両方）があった場合は、コメント横の「⋯」メニューの「⚠️ 報告」から種別とカテゴリを選んで報告いただけます（いただいた報告は将来の改善に活用します）。
